Open in De Raiz

The button opens the app, if it is installed on this phone. The invite works once, and expires seven days after it was created.

This address does not carry a valid code. The code comes at the end of the link, after the #, and is six letters and digits. Check the link with the person who invited you, or ask them to read you the code.

Don’t have the app yet?

De Raiz is an iPhone app and is not on the App Store yet: the person who invited you knows how to install it. Once it is installed, come back to this page and tap Open in De Raiz — or open the app, tap I have an invite to an obra and type the code above.

Joining a shared obra needs an account, which you can create inside the app with Apple, with Google or with an email address.

What this page does with the code

Nothing, beyond showing it. The code comes after the # in the address, and a browser never sends that part to any server — not even the one serving this page. There are no visitor analytics and no third-party scripts here. What decides whether the invite is valid is the De Raiz server, when you tap Join the obra inside the app.

What happens when you accept

The whole obra arrives on your phone and keeps working with no signal. What you write reaches the other members, and what they write reaches you. A shared obra is also kept on a server in the European Union that only that obra’s members can read — the privacy policy says what that means.

De Raiz keeps one obra per phone. If this phone already has one, the app asks you to export and delete it before joining the other — the exported copy is yours.
