Don’t have the app yet?

De Raiz is a free app for iPhone and iPad, on the App Store. Once it is installed, come back to this page and tap Open in De Raiz – or open the app, tap I have an invite to a build and type the code above.

Download on the App Store

Joining a shared build needs an account, which you can create inside the app with Apple, with Google or with an email address.

What this page does with the code

Nothing, beyond showing it and putting it in the two buttons. The code comes after the # in the address, and a browser never sends that part to any server – not the one serving this page, and not the one serving De Raiz on a computer, which reads it the same way and keeps it in the browser until it is used. There are no visitor analytics and no third-party scripts here. What decides whether the invite is valid is the De Raiz server, when you tap Join the build inside the app.

What happens when you accept

The whole build arrives on your phone – or in the browser – and keeps working with no signal. What you write reaches the other members, and what they write reaches you. A shared build is also kept on a server in the European Union that only that build’s members can read – the privacy policy says what that means.

De Raiz keeps one build per phone, and one per browser. If this phone already has one, the app asks you to export and delete it before joining the other – the exported copy is yours.
